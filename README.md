# JupJup Ticket Server

외부 예매 서비스와의 연동을 구현하기 위해 만든 가상 티켓 서버입니다.

공연·티켓 정보와 예약 상태는 **티켓 서버**에서 관리하고, 취소표 감지와 구독자 알림은 **줍줍 서버**에서 처리하도록 역할을 나눴습니다. 예약 생성·확정·취소·만료에 따른 서비스 흐름을 확인할 수 있습니다.

> 전체 프로젝트 소개와 아키텍처는 [JupJup 메인 저장소](https://github.com/ticket-jup-jup/jupjup-api)에서 확인할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 서버·계정 인증 | API Key 발급 및 연동할 사용자 계정 검증 |
| 공연·티켓 조회 | 프로그램, 회차, 좌석 및 티켓 정보 제공 |
| 예약 관리 | 임시 예약 생성, 예약 확정·취소·만료 처리 |
| 취소표 정보 전달 | 예약 취소·만료 시 줍줍 서버로 Webhook 전송 |

줍줍 서버는 이 서버에서 공연·티켓 정보를 조회하고 예약을 요청합니다. 취소표 감지와 사용자 알림 처리는 줍줍 서버에서 담당합니다.
